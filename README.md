# AIBOU · Aprovação de dezembro

Página de aprovação dos posts de dezembro da AIBOU: feed completo, post a post (carrossel, legenda e objetivo), pedido de ajuste por tela e devolutiva em PDF.

## Publicar no GitHub Pages

1. Crie um repositório e suba todo o conteúdo desta pasta (incluindo `.nojekyll`).
2. Em **Settings › Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O link fica em `https://<usuario>.github.io/<repositorio>/`.

## Estrutura

- `index.html` — a página
- `feed-final/jpg/` — telas e capas (NN-C.jpg = post NN, tela C)
- `feed-final/mp4/` — telas em vídeo
- `assets/` — fonte PP Frama Text e foto de perfil

As respostas do cliente ficam salvas só no navegador dele. No fim da página ele baixa a devolutiva em PDF e envia para o estúdio pelo WhatsApp.
